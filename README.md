# SheetNest

Веб-приложение для **раскроя металлических листов**. Загружается чертёж детали, задаются размер листа и требуемое количество, затем программа ищет компактную раскладку и показывает **все листы**.

## Возможности

- произвольный размер металлического листа **ширина × длина в мм**;
- материал и толщина листа;
- поле от края и зазор между деталями;
- количество одинаковых деталей;
- 0°, 180°, 90°/270° или каждые 45°;
- автоматическое сравнение двух ориентаций листа;
- раскладка на все необходимые листы;
- отображение числа листов, деталей и заполнения;
- остановка расчёта с сохранением лучшего найденного решения;
- экспорт раскладки в SVG;
- импорт SVG, DXF и DWG.

## Оптимизация

Внутри используется **NFP/генетический алгоритм SVGnest**. Его целевая функция последовательно минимизирует число непомещённых деталей, количество листов и ширину занятой области.

Режимы поиска:
- Быстро — около 10 с;
- Баланс — около 30 с;
- Максимум — около 90 с.

«Максимально компактная» означает лучший вариант, найденный за заданное время. Для нерегулярного nesting нет гарантии глобального математического оптимума.

## DWG и DXF

DWG преобразуется на сервере через внешний CLI-конвертер DWG→DXF, задаваемый переменной `DWG_CONVERTER`. DXF конвертируется в SVG с вычислением реальных габаритов геометрии, чтобы раскладка не зависела от фиксированного viewBox.

Пример:

```bash
DWG_CONVERTER=/opt/ODAFileConverter/ODAFileConverter npm start
```

## Запуск

```bash
npm install
npm start
```

Открыть http://localhost:3000.
