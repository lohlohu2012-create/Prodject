# SheetNest

Веб-приложение для раскроя деталей на листе: импорт SVG/DXF и DWG через внешний DWG→DXF конвертер, выбор размера листа, отступов и шага поворота, затем автоматическая раскладка.

## Что уже есть

- SVG, DXF и DWG как входные форматы.
- Предустановки листа A4–A0 и произвольный размер.
- Размеры листа в мм, поля и расстояние между деталями.
- Количество экземпляров детали.
- Поворот 0° / 90°.
- Предпросмотр листа и результатов раскладки.
- Скачивание результата в SVG.
- Серверный адаптер для DWG: используется CLI-конвертер, путь к которому задаётся через `DWG_CONVERTER`.

## Важно про DWG

Сам браузер не содержит полноценного DWG-парсера. Поэтому DWG загружается на сервер, после чего сервер вызывает установленный конвертер DWG→DXF. Для промышленного развёртывания можно подключить ODA File Converter или другой совместимый CLI-инструмент.

Пример:

```bash
DWG_CONVERTER=/opt/ODAFileConverter/ODAFileConverter npm start
```

Если конвертер не установлен, SVG и DXF продолжат работать, а попытка загрузить DWG вернёт понятное сообщение.

## Запуск

```bash
npm install
npm start
```

Открыть: http://localhost:3000

## Лицензия

Код этого проекта распространяется по MIT License.

Проект функционально ориентирован на SVGnest (https://github.com/Jack000/SVGnest), который распространяется под MIT License. SVGnest использует генетическую оптимизацию и No-Fit Polygon для нерегулярной укладки. В текущем MVP SheetNest использует более простой и предсказуемый алгоритм раскладки по ограничивающим прямоугольникам; это сделано специально, чтобы разделить импорт/подготовку геометрии и дальнейшую реализацию полноценного NFP-nesting.
