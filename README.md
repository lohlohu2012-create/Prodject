# SheetNest

Веб-приложение для **раскроя металлических листов**.

## Что умеет

- импорт **DXF и SVG**;
- выбор материала и толщины;
- произвольный размер металлического листа в мм;
- технологическое поле от края;
- зазор между деталями;
- заданное количество одинаковых деталей;
- выбор допустимых поворотов;
- NFP / генетический поиск компактной раскладки;
- раскладка на все необходимые листы;
- визуализация листа с полем, зазором, номерами деталей и габаритами;
- просмотр заполнения и количества листов;
- экспорт результата в SVG.

## DXF

DWG полностью исключён из интерфейса и серверной части. Основной входной CAD-формат теперь DXF.

DXF разбирается прямо в браузере и преобразуется в SVG с сохранением фактических габаритов геометрии, после чего SVGnest выполняет нерегулярную раскладку. Запрос к `/api/import/dxf` больше не требуется.

## Запуск

Node.js/Express теперь не требуется для работы интерфейса и импорта DXF.

Откройте `public/index.html`. Для браузеров, которые блокируют Web Workers при `file://`, используйте любой статический HTTP-сервер, например:

```bash
python -m http.server 8000
```

и откройте `http://localhost:8000/public/`.

`server.js` оставлен в репозитории как совместимый legacy-вариант запуска через Express, но клиент больше от него не зависит.

## Оптимизация

Цель поиска: минимум листов → максимум заполнения → компактная геометрия. «Максимум» в интерфейсе означает больше времени на поиск лучшего найденного решения; математическая гарантия глобального оптимума отсутствует, как и у большинства эвристических методов нерегулярной упаковки.

## Деловые остатки

SheetNest поддерживает смешанный раскрой: при включённой опции сначала проверяются сохранённые деловые остатки, затем оставшиеся детали раскладываются на новых листах.

Минимальный деловой остаток задаётся двумя независимыми параметрами:
- минимальная длина, мм;
- минимальная ширина, мм.

Проверяются обе ориентации остатка: L × W и W × L, поэтому остаток 300 × 500 мм проходит при настройках 500 × 300 мм. Для сложных полигонов используется реальная геометрия свободного металла, а не только bounding box; проверка учитывает технологический зазор.

Свободные полигоны после раскроя могут сохраняться локально и использоваться в следующем расчёте. При использовании остатка он помечается как потреблённый, а новые свободные полигоны сохраняются как дочерние остатки.


## Экспорт DXF

После расчёта раскроя доступна кнопка «Экспорт DXF». Каждый результат раскроя выгружается отдельным DXF-файлом. В файл входят контур листа или делового остатка и контуры размещённых деталей в реальных координатах; для деталей сохраняется слой с instanceId/unitId, когда он доступен. Экспорт работает локально в браузере и не требует Node.js, сервера или интернета.
