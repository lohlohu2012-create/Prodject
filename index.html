SheetNest

Раскрой металлических листов: DXF / SVG, количество деталей, размер листа и оптимизированная NFP-раскладка.

Node.js-сервер для импорта DXF больше не нужен: DXF и SVG обрабатываются прямо в браузере.

Открыть приложениеGitHub

Для локального запуска просто откройте public/index.html. Для полноценной работы Web Workers в некоторых браузерах используйте любой статический HTTP-сервер.
