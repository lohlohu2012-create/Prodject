SheetNest

Раскрой металлических листов: DWG / DXF / SVG, количество деталей, размеры листа и оптимизированная NFP-раскладка.

Для полноценной работы откройте приложение через локальный сервер. Это нужно, потому что веб-воркеры и загрузка файлов работают надёжнее через http://localhost, а DWG требует серверного конвертера.

Открыть приложение GitHub

Запуск локально: python -m http.server 8000, затем http://localhost:8000/public/.
